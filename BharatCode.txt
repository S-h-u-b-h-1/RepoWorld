PROJECT IN ONE SENTENCE
Explore unfamiliar public GitHub repositories as interactive 3D code cities,
find relevant modules, and investigate open-source issues with source-aware,
optional BharatCode-powered assistance.

TRY THE WORKING PROJECT

Free startup-friendly launcher: https://repoworld-launch.onrender.com
Live application: https://repoworld-3b9e.onrender.com
Example public repository: https://github.com/zulip/zulip-terminal

Open the launcher, follow the link to RepoWorld, and confirm an import of
"zulip/zulip-terminal". Explore its 3D districts and module buildings. Click a
building to inspect indexed source paths and sampled static-import links; use
Explore code > Find code to search; use Open issues (Issue Radar) to inspect
reported GitHub issues and their qualified location hints. The assistant is
optional, and its live inference depends on BharatCode provider availability.

WHAT BHARATCODE POWERS
RepoWorld integrates the BharatCode Qwen model through a server-side
chat-completions API for optional source-scoped architectural questions,
repository exploration, and issue investigation guidance. The API key is
configured privately on the server and is never included in this repository.
If the provider is unavailable, times out, or the model output cannot be
supported, RepoWorld labels the fallback rather than pretending AI ran.
The visual city, code/path discovery, and labeled public issue exploration
remain useful independently of successful model inference.

TECHNICAL NOTES AND LIMITATIONS
The detailed disclosures below describe the read-only architecture, public
source provenance, safeguards, rate limits, and Render Free behavior.

RepoWorld is an anonymous, read-only explorer for PUBLIC GitHub repositories. No
GitHub/Google login or account signup is required. A user pastes a public
repository URL and explores a 3D city with districts for subsystems and buildings
for source modules. Optional illuminated links show only sampled STATIC imports,
not verified runtime execution. File discovery, source search, and change-impact
tracing are intentionally evidence-limited. A city link contains only the public
owner/repo name; it never shares guest-session credentials or source snippets.
An explicit local offline map backup can preserve a bounded, sanitized public
module/filename graph in the visitor's own browser. It cannot make live AI,
GitHub issues or other server endpoints work after the free instance loses
its guest SQLite workspace; returning to live tools requires a confirmed re-import.
A public city can also be downloaded as a versioned, sanitized browser-local
JSON file and manually restored on another device without uploading it to
RepoWorld. A restored file is unverified offline metadata, never an authenticated
server snapshot, current GitHub state or working live AI source.
New visitors must confirm a GitHub import before any external repository fetch.

Issue Radar retrieves reported open GitHub issues, excludes pull requests, and
labels building placements as referenced, suggested or unplaced. Clicking an issue
shows its original report and optional AI investigation. Source discovery checks
a bounded sample of paths from the current public GitHub tree. Fetched source
excerpts, not issue-provided code snippets, are the basis for code-evidence claims.
Where GitHub supplies a commit SHA, the assistant can link to commit-pinned
source excerpts and line ranges. No code is executed or modified by RepoWorld.

BharatCode Qwen 3.8 27B is integrated through a server-side chat-completions API.
The model is used for optional architecture explanations, questions about public
source code, and issue investigation plans. The model API key stays on the server.
If the key is absent or the provider times out, RepoWorld labels deterministic
navigation guidance instead of claiming to have generated an AI answer.

AI guidance is not independently validated code correctness, defect reproduction,
fix execution or test results. Model outputs should be checked against the
linked source and relevant project tests. Anonymous access is protected with
per-browser and global budgets, but a public launch also requires hosting-level
abuse protection.

On Render Free, when the server receives a GitHub API rate-limit response,
RepoWorld can fetch a limited open-issue page directly in the visitor's browser
using the public GitHub CORS API, without a visitor login or server secret.
That feed is explicitly labeled not independently verified by the server.
Browser-fed reported paths remain unverified suggestions. A visitor may explicitly
request a separate, quota-limited lookup of actual public source files from the
saved repository; this checks source bytes, NOT whether the browser-reported issue
is real, open, correctly located, or independently reproduced. It never triggers
BharatCode inference or upgrades issue markers. Server-verified AI issue
investigation still requires authenticated GitHub issue access.
